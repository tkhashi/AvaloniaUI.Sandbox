# 検証報告書

## 1. 概要
- 対象: macOS 向けグローバルホットキー検証
- プロジェクト: `HotkeyTest`（.NET 10 / Avalonia）
- 目的: バックグラウンド常駐し、ホットキー押下時にアクティブウィンドウ情報を取得し、スクリーン解析結果をオーバーレイ表示、かつログを出力できることを確認する。

## 2. 実装構成
- 常駐起動/アプリ初期化: `HotkeyTest/Program.cs`, `HotkeyTest/App.cs`
- グローバルホットキー監視（macOS EventTap）: `HotkeyTest/MacGlobalHotkeyListener.cs`
- アクティブウィンドウ取得/画像輝度解析: `HotkeyTest/MacWindowInspector.cs`
- オーバーレイ表示: `HotkeyTest/OverlayWindow.cs`
- ログ出力: `HotkeyTest/FileLogger.cs`
- プロジェクト設定: `HotkeyTest/HotkeyTest.csproj`（`OutputType=Exe`, `TargetFramework=net10.0`）

## 3. 検証条件
- OS: macOS
- フレームワーク: .NET 10
- UI: Avalonia
- ホットキー: `Cmd + Shift + M`
- ログ出力先: 本ディレクトリ直下 `hotkey-test.log`

- `CGEventTapCreate 成功`
- `ホットキーイベントループ開始`
- `key-event: keyCode=46, flags=0x120112, matched=True`
- `ホットキー条件一致: Cmd+Shift+M`
- `ホットキー押下: process=システム設定, pid=80798, window=4822, x=364, y=211, w=715, h=629, luminance=0.000`

## 6. 補足事項
- 入力監視権限: `granted` を確認済み。
- 画面収録権限: ログ上 `not-granted` のため、画像解析（平均輝度）が 0.000 となるケースを確認。
- 画面収録を許可した上で再起動した場合、`luminance` が 0 以外になることを追加確認対象とする。

### HotkeyResult の `x`, `y` について
- `x`, `y` は「アクティブウィンドウ矩形の左上座標」を示す。
- 取得元は macOS `CGWindowListCopyWindowInfo` の `kCGWindowBounds` 内 `X`, `Y`。
- 実装上は `MacWindowInspector.TryGetFrontWindowContext()` で `GetDoubleFromBoundsDictionary(dict, "X")` / `("Y")` を読み取り、`HotkeyResult.X` / `Y` に格納している。
- したがって `x`, `y` はマウスカーソル座標ではなく、前面ウィンドウの画面座標（グローバル座標系）である。

## 7. 総合判定
- 本検証の主目的（常駐・ホットキー捕捉・アクティブウィンドウ情報取得・オーバーレイ表示・ログ出力）は達成。
- スクリーン解析値の有効性は、画面収録権限付与後に最終確認することで完了とする。
