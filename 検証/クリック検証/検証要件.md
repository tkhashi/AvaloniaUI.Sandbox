# マウスカーソルの操作実装
- 対象OS:MacOS
- Accessibility APIを利用して特定のウィンドウの要素をクリックする
- 1. 右クリックさせることができるか
- 2. 左クリックさせることができるか
- 3. ダブルクリック（左クリック）させることができるか
- 上記1~3をUIでボタン押下時に実行する
  - UIではじめに現在開いているウィンドウを一覧表示する
  - その後ユーザーが選択したウィンドウの要素一覧を取得し、その要素に対して右/左/ダブルクリックするボタン押下で実行する
- Accesibility UIの検証は `/Users/kazuhiro.takahashi/Documents/github/AvaloniaUI.Sandbox/検証/AccessibilityApi検証` で一部行っているので使用すること。
- 実行した結果がわかるようにログファイルをこのディレクトリ配下に配置。

# 技術要件

- AvaloniaUI
