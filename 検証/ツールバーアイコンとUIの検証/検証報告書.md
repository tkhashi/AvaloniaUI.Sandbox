# ツールバーアイコンとUIの検証報告書

## 1. 概要
- 対象: macOS のメニューバー（ネイティブツールバー）アイコン + メニューバー項目 + GUI表示
- プロジェクト: `ToolbarIconUiVerificationApp`（.NET 10 / Avalonia）
- 目的: バックグラウンド常駐状態で、メニューバーアイコンを配置し、メニュー項目からGUI表示/非表示できるかを検証する。

## 2. 実装構成
- ソリューション: `ToolbarIconUiVerification.slnx`
- アプリ起動: `ToolbarIconUiVerificationApp/Program.cs`
- 常駐制御/トレイアイコン/メニュー制御: `ToolbarIconUiVerificationApp/App.axaml.cs`
- 通常GUI: `ToolbarIconUiVerificationApp/MainWindow.axaml`
- ログ出力: `ToolbarIconUiVerificationApp/Services/AppLogger.cs`
- アイコン画像: `ToolbarIconUiVerificationApp/Assets/shark.png`

## 3. 実施環境
- OS: macOS
- Framework: .NET 10.0
- UI Framework: Avalonia 11.3.12

## 4. 検証結果

| No | 検証項目 | 期待結果 | 結果 | 判定 |
|---|---|---|---|---|
| 1 | バックグラウンド常駐起動 | 起動時にメインGUIを表示せず常駐 | `ShutdownMode.OnExplicitShutdown` + メインWindow非自動表示で実装 | OK |
| 2 | メニューバーアイコン表示 | macOSネイティブメニューバーにアイコン表示 | `TrayIcon` 初期化成功ログを確認 | OK |
| 3 | メニューからGUI表示 | `GUIを表示` で通常GUIが表示される | `NativeMenuItem("GUIを表示")` で `MainWindow.Show()` 実装 | OK |
| 4 | メニューからGUI非表示 | `GUIを隠す` で通常GUIが非表示になる | `NativeMenuItem("GUIを隠す")` で `Hide()` 実装 | OK |
| 5 | GUIを閉じても常駐継続 | GUIを閉じてもアプリ終了しない | `Closing` をキャンセルして `Hide()` に変換 | OK |
| 6 | 明示終了 | メニュー「終了」でのみ終了 | `NativeMenuItem("終了")` で `desktop.Shutdown()` 実装 | OK |

## 5. 追加検証（GIFアイコン）
- 実施日: 2026-03-01
- 内容: `Assets/minecraft.gif` をトレイアイコンに差し替えて表示確認
- 結果: ユーザー確認にて期待動作せず（アニメーションGIFアイコンとして利用不可と判定）
- 対応: アイコンを `Assets/shark.png` へ戻した
